# 开发文件说明

普通使用者只需打开上一级的「视频码率计算器.html」。这里的 Python / Node 文件不参与日常运行，无需安装开发环境。

`original/bitrate_core.py` 和 `original/test_bitrate_core.py` 是找到的旧版文件的逐字节副本，作为公式、阈值和元数据测试的参考，未改写。原版预设文案不代表本次 Mac 软件推荐；以主 HTML 及「Mac压制软件选择.md」为准。

在本目录中复查（开发者环境，Python 3.10+、当前 Node.js）：

```sh
python3 -B -m unittest discover -s original -p 'test_bitrate_core.py' -v
python3 -B generate_reference.py
node test_calculator.mjs
```

Windows 的 Python 命令可用 `python` 代替 `python3`。

`reference_vectors.json` 包含原版直接生成的 216 组预算和 216 组建议结果，主测试读取 HTML 中实际内嵌的计算代码，不另存一套实现。

主测试里的 DOM stub 仅检查控制器接线、失效结果清空和复制调用的参数；它不渲染页面，也不证明真实剪贴板、文件选择、下载或 Safari 功能正常。

本次先运行最小失败检查，再根据拒绝覆盖日志与文件哈希修正验证脚本对 FFmpeg 返回码的错误假设；使用现有 Python / Node 测试工具完成等效的失败复现与验证，未安装额外测试技能或依赖。该辅助检查不属于用户日常使用文件。
